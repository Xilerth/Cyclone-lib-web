# Proyecto Cyclone

Librería de componentes para **Web Components**, *Angular* y *React*.

## Características

- Tokens de diseño desde un JSON
- Data grid con `agrupación` y exportación
- Accesible por defecto

> Construido una sola vez, usado en todas partes.

```ts
import { toast } from '@cyclone-lib/core';
toast('Hola');
```

Más información en [la documentación](https://example.com).
